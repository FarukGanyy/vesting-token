Vesting-Token
The Vesting Token is a Clarity smart contract that implements linear vesting schedules on top of a fungible token.
It allows tokens to be released gradually over time, ensuring fairness for teams, investors, and community members.

Features
Linear vesting release
Lock tokens for beneficiaries
Claim vested tokens anytime
Transparent on-chain vesting data
Event logs for vesting creation and claims

Technical Overview
Language: Clarity
Core Functions:
create-vesting – start a vesting schedule
claim-vested – claim unlocked tokens
get-vesting-info – fetch vesting details
